# live_bots — اسنپ‌شات همهٔ بات‌های زندهٔ تیم‌یار

آینهٔ **فقط-خواندنی** از سورس همهٔ بات‌های `erp.bimehland.com`، برای اینکه گیت‌هاب یک نسخهٔ کامل و قابل‌دیف
از وضعیت سرور داشته باشد.

## این پوشه چه چیزی هست و چه چیزی نیست

- **هست**: خروجی خام `bot_command.command` هر بات، همان‌طور که روی سرور ذخیره شده — بدون هیچ ویرایش،
  اصلاح یا فرمت‌کردن. عمداً byte-identical نگه داشته می‌شود تا دیف با سرور معنا داشته باشد.
- **نیست**: سورس authored پروژه. بات‌هایی که در این ریپو توسعه داده می‌شوند در `src/*_bot.lua` هستند و
  `docs/context/TeamyarBotsLiveRegistry.json` نگاشت `id → local_src` را نگه می‌دارد. برای ویرایش یا دیپلوی
  **همیشه `src/` مرجع است، نه این پوشه.**

## ساختار

| مسیر | محتوا |
|---|---|
| `{id}.lua` | سورس بات با همان `bot_command.ID` |
| `INDEX.json` | فهرست هر ۳۹۹ بات: `id`, `name`, `description`, `disabled`, `open_source`, `source_version`, `run_count`, `source_bytes`, `file` |

۴۰ بات از ۳۹۹ تا روی سرور `source_code` خالی دارند، پس فایل `.lua` ندارند — در `INDEX.json` با `file: ""`
مشخص شده‌اند.

## نحوهٔ تولید / به‌روزرسانی

از طریق بات ۵۸۷ (`getallbots`) که کل جدول بات‌ها را در یک فراخوانی برمی‌گرداند:

```bash
curl -X POST 'https://erp.bimehland.com/bot/run/443/getallbots?ver=0' -H "Cookie: SID=$TEAMYAR_SID" -o dump.json
```

سپس هر `bots[].source_code` در `live_bots/{id}.lua` نوشته می‌شود.

## هشدارهای مهم

- **نسخهٔ زندهٔ بعضی بات‌ها خراب است.** باگ تأییدشدهٔ پلتفرم هنگام ذخیرهٔ `command` رشته‌های Entity را
  Decode می‌کند (`&amp;` → `&`، `&times;` → `×`، `&section=` → `§ion=`). بات‌های ۵۶۵، ۵۸۶، ۵۹۹ و ۶۰۶ در این
  اسنپ‌شات همین خرابی را دارند و زنجیرهٔ `escape_html` دو تای اول حتی بریده شده. **نسخهٔ `src/` این بات‌ها
  درست است — از این پوشه روی `src/` کپی نکنید.** جزئیات در `CLAUDE.md`، بخش Security Rules.
- **این اسنپ‌شات لزوماً هم‌ارز `src/` نیست.** در زمان تولید، بات ۶۰۴ روی سرور از `src/` عقب‌تر بود
  (v04.1 هنوز دیپلوی نشده بود).
- سورس‌ها بدون ماسک منتشر شده‌اند تا مرجع دیف سالم بماند؛ یعنی هر آدرس یا شناسهٔ داخلی که داخل کد بات‌ها
  هاردکد شده، اینجا هم هست.
