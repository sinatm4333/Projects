# ویرایش اقدام

ویرایش تسک

## آدرس

```
/api/todo/taskedit
```

## درخواست

```json
{
  "color": "",
  "wf_id": 0,
  "task_id": 0,
  "deadline": 0,
  "owner_id": 0,
  "priority": 0,
  "topic_id": 0,
  "task_title": "",
  "category_id": 0,
  "portal_show": 0
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `color` | string | رنگ اقداممقدار این فیلد اجباری نمی باشد .درصورتی که این فیلد مقدار دهی نشود رنگ تسک مقدار قبلی خود را حفظ خواهد کرد.مثال: #ff0000 - #0000ff -#ffa500 - #ffff00 |
| `wf_id` | integer (int64) | شناسه جریان کاروارد کردن مقدار این فیلد اجباری نمی باشد.درصورتی که این فیلد مقدار رهی نشود تسک مقدار قبلی جریان کار خود را حفظ خواهد کرد.درصورتی که جریان کار را تغییر دهیم جریان کار بعدی به تسک اضافه خواهد گردید.در صورتی که مقادیر اشتباه به این فیلد دهیم ارور برگردانده می شود. |
| `task_id` | integer (int64) | ***شناسه اقداموارد کردن مقدار برای این فیلد اجباری می باشد.درصورت وارد نکردن مقدار یا مقادیر اشتباه ارور باز گردانده میشود. |
| `deadline` | integer (int64) | مهلت اقداموارد کردن مقدار برای این فیلد اجباری نمی باشد . |
| `owner_id` | integer (int64) | مقداردهی این فیلد اجباری نمی باشد |
| `priority` | integer (int32) | اولویت اقداممقداردهی این فیلد اجباری نمی باشد. |
| `topic_id` | integer (int64) | شناسه موضوع اقداممقداردهی این فیلد اجباری نمی باشد.در صورت اشتباه وارد کردن مقدار ارور بازگردانده میشود. |
| `task_title` | string | عنوان اقداممقدار دهی این فیلد اجباری نمی باشد. |
| `category_id` | integer (int64) | شناسه رده اقداممقداردهی این فیلد اجباری نمی باشد.در صورت وارد کردن مقادیر اشتباه تغییری در تسک صورت نمیپذیرد. |
| `portal_show` | integer (int32) |  |

## پاسخ

```json
{
  "data": {
    "task_id": 0
  },
  "error": {
    "status": 0,
    "message": ""
  },
  "success": false
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `data` | object | دیتا |
| `data.task_id` | integer (int64) | شناسه اقدام |
| `error` | object | جزئیات خطای اجرای API |
| `error.status` | integer (int32) | 1-کدخطا |
| `error.message` | string | پیغام خطا |
| `success` | boolean | نشان دهنده وضعیت اجرای API، مقدار true در صورت موفقیت و مقدار false در صورت مواجه شدن با خطا |
