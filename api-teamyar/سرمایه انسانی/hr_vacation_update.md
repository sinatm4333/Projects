# بروزرسانی مرخصی/مأموریت

ایجاد یا ویرایش مرخصی/مأموریت

## آدرس

```
/api/hr/vacation_update
```

## درخواست

```json
{
  "id": 0,
  "kind": 0,
  "type": 0,
  "day_to": 0,
  "org_id": 0,
  "time_to": 0,
  "add_link": 0,
  "day_from": 0,
  "city_type": 0,
  "time_from": 0,
  "customform": "",
  "description": "",
  "personnel_id": 0
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `id` | integer (int64) | شناسه مرخصی/مأموریتبرای ایجاد، مقدار 0 و برای ویرایش، مقدار مربوطه وارد شود. |
| `kind` | integer (int32) | نوع مرخصی (کاربرد برای مرخصی) |
| `type` | integer (int32) | نحوه مرخصی/مأموریت (روزانه یا ساعتی) |
| `day_to` | integer (int64) | تاریخ پایان بازه مرخصی/مأموریتدر ویرایش مرخصی/مأموریت یا ایجاد مرخصی/مأموریت برای یک روز و یا در ثبت از نوع ساعتی، این تاریخ با تاریخ شروع بازه، یکی باید باشد. |
| `org_id` | integer (int64) | شعبه |
| `time_to` | integer (int64) | ساعت پایان مرخصی/مأموریت ساعتی |
| `add_link` | integer (int32) | در صورت true، لینک در هنگام ایجاد یا ویرایش مأموریت، اضافه می شود. |
| `day_from` | integer (int64) | تاریخ شروع بازه مرخصی/مأموریت |
| `city_type` | integer (int32) | نوع مأموریت (درون شهری، برون شهری، برون کشوری) |
| `time_from` | integer (int64) | ساعت شروع مرخصی/مأموریت ساعتی |
| `customform` | string | اطلاعات فرم سفارشی |
| `description` | string | توضیحات |
| `personnel_id` | integer (int64) | شناسه کارمند مربوطه |

## پاسخ

```json
{
  "data": {
    "message": ""
  },
  "error": {
    "status": 0,
    "message": ""
  },
  "success": false
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `data` | object |  |
| `data.message` | string | شناسه های مرخصی/مأموریت های ثبت شده در این پیغام بازگردانده می شوند. |
| `error` | object | جزئیات خطای اجرای API |
| `error.status` | integer (int32) | کد خطا |
| `error.message` | string | پیغام خطا (در صورت خطا دار بودن) یا پیغام هشدار (در صورت موفق بودن بروزرسانی) |
| `success` | boolean | نشان دهنده وضعیت اجرای API، مقدار true در صورت موفقیت و مقدار false در صورت مواجه شدن با خطا |
