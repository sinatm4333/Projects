# ایجاد اقدام

لطفا با دقت مطالعه شود.

## آدرس

```
/api/todo/taskadd
```

## درخواست

```json
{
  "wf_id": 0,
  "crm_id": 0,
  "comment": "",
  "deadline": 0,
  "topic_id": 0,
  "task_type": 0,
  "project_id": 0,
  "task_title": "",
  "parent_step_id": 0,
  "parent_task_id": 0
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `wf_id` | integer (int64) | شناسه جریان کار، این شناسه باید معتبر باشد در غیر این صورت error برگردانده میشود و اقدام افزوده نمیشود، جریان کار انتخابی باید حتما مرحله ی شروع داشته باشد در غیر این صورت error برگردانده میشود، ***مقدار دهی اجباری است |
| `crm_id` | integer (int64) | شناسه مشتری که میخواهید با اقدام ایجاد شده لینک شود، امکان اینکه این فیلد مقدار دهی نشود وجود دارد و اجباری نیست، در صورتی که این شناسه معتبر نباشد با اقدام لینک نمیشود و باز دارنده نیست |
| `comment` | string | محتوای کامنتی که میخواهید همراه ایجاد اقدام در مرحله ی اول افزوده شود، امکان اینکه این فیلد مقدار دهی نشود وجود دارد و اقدام بدون کامنت افزوده میشود، کامنت شما تا 50 هزار کارکتر میتواند باشد در صورتی که از این مقدار بیشتر باشد error برگردانده میشود |
| `deadline` | integer (int64) | تاریخ مهلت اقدام، در صورتی که این تاریخ قبل از تاریخ فعلی باشد یا خالی باشد به صورت پیش فرض 7 روز اینده در نظر گرفته میشود، امکان اینکه این فیلد مقدار دهی نشود وجود دارد و اجباری نیست مقدار پیش فرض میگیرد |
| `topic_id` | integer (int64) | شناسه موضوع، این شناسه باید معتبر باشد در غیر این صورت error برگردانده میشود و اقدام افزوده نمیشود، ***مقداردهی اجباری است |
| `task_type` | integer (int32) | نوع اقدام، در صورتی که بخواهید اقدام نورمال ایجاد کنید باید مقدار 1 مقداردهی کنید، در صورتی که بخواهید اقدام پورتال ایجاد کنید باید مقدار 4 مقداردهی کنید، در صورتی که مقدار نداشته باشد مقدار پیش فرض 1 در نظر گرفته میشود |
| `project_id` | integer (int64) | شناسه پروژه، در صورتی که این فیلد مقدار دهی شود اقدام ایجاد شده به stage های این پروژه افزوده میشود، امکان اینکه این فیلد مقدار دهی نشود وجود دارد |
| `task_title` | string | عنوان اقدام، در صورتی که مقدار نداشته باشد عنوان پیش فرض جریان کار استفاده میشود و در صورتی که جریان کار هم عنوان پیش فرض نداشته باشد empty title به جای عنوان قرار میگیرد، ***بهتر است حتما این فیلد مقدار دهی شود |
| `parent_step_id` | integer (int64) | شناسه مرحله ی اقدامی که به وسیله ان این اقدام قرار است ایجاد شود |
| `parent_task_id` | integer (int64) | شناسه اقدامی که به وسیله ان این اقدام قرار است ایجاد شود |

## پاسخ

```json
{
  "data": {
    "task_id": 0
  },
  "error": {
    "status": 0,
    "message": ""
  },
  "success": false
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `data` | object | response object |
| `data.task_id` | integer (int64) | شناسه اقدامی که ایجاد میشود |
| `error` | object | response error object |
| `error.status` | integer (int32) | وضعیت فراخوانی Api |
| `error.message` | string | در صورتی که Api موفق اجرا نشود در این پارامتر Error برگردانده شده نمایش داده میشود |
| `success` | boolean | موفق بودن اجرای Api را نشان میدهد، در صورتی که api با موفقیت اجرا شود مقدار true دارد در غیر این صورت false |
