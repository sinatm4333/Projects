# درخواست توکن یکبار مصرف

دریافت توکن یکبار مصرف به ازای IP و رشته متنی (شماره موبایل، ایمیل و ...) برای درخواست کننده

## آدرس

```
/api/token/request_token
```

## درخواست

```json
{
  "ip": "",
  "receiptant": ""
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `ip` | string | IP درخواست کننده |
| `receiptant` | string | اطلاعات گیرنده (شماره موبایل، ایمیل، آی دی تلگرام یا ...) -> تاثیر گذار بر مقدار توکن ایجاد شده |

## پاسخ

```json
{
  "data": {
    "token": "",
    "result": 0,
    "next_time": 0,
    "expire_time": 0
  },
  "error": {
    "status": 0,
    "message": ""
  },
  "success": false
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `data` | object |  |
| `data.token` | string | مقدار توکن یکبار مصرف تولید شده |
| `data.result` | integer (int32) | نتیجه فرایند تولید توکن |
| `data.next_time` | integer (int64) | اوین زمان امکان درخواست توکن جدید برای IP و گیرنده وارد شده |
| `data.expire_time` | integer (int64) | زمان انقضاء توکن یکبار مصرف دریافت شده (تا قبل از این زمان، توکن برای اعتبارسنجی معتبر است) |
| `error` | object | جزئیات خطای اجرای API |
| `error.status` | integer (int32) | کد خطا |
| `error.message` | string | پیغام خطا |
| `success` | boolean | نشان دهنده وضعیت اجرای API، مقدار true در صورت موفقیت و مقدار false در صورت مواجه شدن با خطا |
