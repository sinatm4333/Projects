# راهنمای استفاده از بات گزارش زمان‌بندی

## توضیحات
این بات گزارش زمان‌بندی فرآیند پذیرش خدمات را تولید می‌کند و شامل زمان‌های مختلف از پذیرش تا تکمیل می‌باشد.

## پارامترهای ورودی

بات نیاز به یک پارامتر ورودی دارد:

1. **startDate**: تاریخ شروع (به فرمت FILETIME)

### مثال:
```lua
input = {
    startDate = 133553931600000000
}
```

**نکته**: کوئری تمام رکوردهایی را که تاریخ پذیرش آنها از `startDate` به بعد است، نمایش می‌دهد (بدون محدودیت تاریخ پایان).

## خروجی

بات یک گزارش HTML تولید می‌کند که شامل جدولی با ستون‌های زیر است:

1. ردیف
2. شماره پذیرش
3. تاریخ پذیرش
4. ماه
5. سال
6. پذیرش توسط
7. وضعیت پذیرش
8. کد کالا
9. مدل کالا
10. کارشناس
11. تفاوت تخصیص
12. وضعیت هزینه
13. تفاوت هزینه
14. تعداد درخواست قطعه
15. تفاوت قطعه
16. تفاوت اولین اقدام
17. تفاوت عملیات
18. تفاوت کارشناس
19. تفاوت QC
20. تفاوت کل
21. تفاوت پیش پذیرش

## رنگ‌بندی

- **سبز (good)**: زمان‌های مناسب
  - تفاوت کل: ≤ 7 روز
  - تفاوت پیش پذیرش: ≤ 1 روز

- **زرد (warning)**: زمان‌های هشدار
  - تفاوت کل: > 15 و ≤ 30 روز
  - تفاوت پیش پذیرش: > 3 و ≤ 7 روز

- **قرمز (critical)**: زمان‌های بحرانی
  - تفاوت کل: > 30 روز
  - تفاوت پیش پذیرش: > 7 روز

## نکات مهم

1. کوئری فقط پذیرش‌هایی را نمایش می‌دهد که:
   - `FINAL_STATUS` در (3, 6, 8, 9) باشد
   - `FINAL_STATUS >= 3` و `FINAL_STATUS <> 5` باشد

2. تاریخ‌ها باید به فرمت FILETIME باشند (مثال: 133553931600000000)

3. در صورت عدم وجود داده، پیام "هیچ داده‌ای برای بازه زمانی مشخص شده یافت نشد" نمایش داده می‌شود

4. در صورت عدم وارد کردن `startDate`، پیام "تاریخ شروع وارد نشده است" نمایش داده می‌شود

## تغییرات نسبت به کوئری اصلی

- تاریخ hard-coded (`133553931600000000`) به پارامتر تبدیل شد
- پارامتر `startDate` اضافه شد (بدون محدودیت تاریخ پایان)
- HTML template با رنگ‌بندی مناسب اضافه شد
- فرمت کردن اعداد برای نمایش بهتر
