# بروزرسانی فیلد سفارشی

آپدیت فیلدهای سفارشی استیج پروژه

## آدرس

```
/api/project/customfieldupdate
```

## درخواست

```json
{
  "stage_id": 0,
  "custom_field": ""
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `stage_id` | integer (int64) | شناسه استیج پروژهوارد کردن این فیلد اجباری می باشد. |
| `custom_field` | string | فیلد سفارشینام فیلد سفارشی در دیتا بیس کلید جیسون و مقداری که اختصاص می دهیم مقدار کلید می باشد.لطفا فرمت جیسون را مانند مثال بنویسید.در صورتی که فیلدهای سفارشی شما معتبر نباشد ارور باز گردانده می شود.در صورتی که میخواهید فیلد سفارشی تغییر نکند در جیسون واردش نکنید. |

## پاسخ

```json
{
  "data": {
    "stage_id": 0
  },
  "error": {
    "status": 0,
    "message": ""
  },
  "success": false
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `data` | object | دیتا |
| `data.stage_id` | integer (int64) | شناسه استیج پروژه |
| `error` | object | جزئیات خطای اجرای API |
| `error.status` | integer (int32) | کد خطا |
| `error.message` | string | پیغام خطا |
| `success` | boolean | نشان دهنده وضعیت اجرای API، مقدار true در صورت موفقیت و مقدار false در صورت مواجه شدن با خطا |
