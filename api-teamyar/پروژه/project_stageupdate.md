# ویرایش استیج های پروژه

لطفا دقیق مطالعه شود.

## آدرس

```
/api/project/stageupdate
```

## درخواست

```json
{
  "title": "",
  "amount": 0,
  "date_end": 0,
  "progress": 0,
  "stage_id": 0,
  "date_start": 0,
  "description": ""
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `title` | string | نامی که میخواهید برای مرحله پروژه اختصاص دهید.، در صورتی که مرحله پروژه به جایی لینک شده باشد این فیلد نام را تغییر نمیدهد.، امکان اینکه این فیلد مقدار دهی نشود وجود دارد و نام "بدون عنوان" جایگزین مقدار قبلی میشود.، مقداردهی اجباری نمی باشد و بازدارنده نیست. |
| `amount` | integer (int64) | هزینه ای که میخواهید برای مرحله پروژه اختصاص دهید.امکان اینکه این فیلد مقدار دهی نشود وجود دارد و عدد قبلی تغییری نمیکند.مقداردهی اجباری نمی باشد و بازدارنده نیست. |
| `date_end` | integer (int64) | تاریخ پایان پروژهدر صورتی که این فیلد خالی باشد تاریخ روز ویرایش +7 جایگزین مقدار قبلی میگردد.امکان اینکه این فیلد مقدار دهی نشود وجود دارد و اجباری نیست . |
| `progress` | integer (int32) | درصد پیشرفتی که میخواهید در مرحله پروژه نمایش دهد.امکان اینکه این فیلد مقدار دهی نشود وجود دارد و عدد قبلی تغییری نمیکند.مقداردهی اجباری نمی باشد و بازدارنده نیست. |
| `stage_id` | integer (int64) | شناسه مرحله پروژه، این شناسه باید معتبر باشد در غیر این صورت error برگردانده میشود و مرحله پروژه بروزرسانی نمیشود، ***مقدار دهی اجباری است |
| `date_start` | integer (int64) | تاریخ شروع مرحله پروژهدر صورتی که این فیلد خالی باشد تاریخ روز ویرایش جایگزین مقدار قبلی میگردد.امکان اینکه این فیلد مقدار دهی نشود وجود دارد و اجباری نیست . |
| `description` | string | توضیحات مرحله پروژه، در صورتی که این فیلد خالی باشد مقدار خالی را میگیرد و توضیحی را نمایش نمیدهد.، امکان اینکه این فیلد مقدار دهی نشود وجود دارد و اجباری نیست . |

## پاسخ

```json
{
  "data": {
    "stage_id": 0
  },
  "error": {
    "status": 0,
    "message": ""
  },
  "success": false
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `data` | object | response object |
| `data.stage_id` | integer (int64) | شناسه مرحله پروژه ای که بروزرسانی میشود |
| `error` | object | response error object |
| `error.status` | integer (int32) | وضعیت فراخوانی Api |
| `error.message` | string | در صورتی که Api موفق اجرا نشود در این پارامتر Error برگردانده شده نمایش داده میشود |
| `success` | boolean | موفق بودن اجرای Api را نشان میدهد، در صورتی که api با موفقیت اجرا شود مقدار true دارد در غیر این صورت false |
