# اعتبارسنجی مقدار وارد شده توکن توسط کاربر

بررسی اینکه آیا توکن ورودی توسط کاربر، با توکن تولید شده بر اساس اطلاعات کاربر یکسان است یا نه

## آدرس

```
/api/token/compare_token
```

## درخواست

```json
{
  "ip": "",
  "token": "",
  "receiptant": ""
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `ip` | string | IP درخواست کننده |
| `token` | string | مقدار توکن وارد شده برای اعتبارسنجی |
| `receiptant` | string | اطلاعات گیرنده (شماره موبایل، ایمیل، آی دی تلگرام یا ...) |

## پاسخ

```json
{
  "data": {
    "result": 0,
    "next_time": 0,
    "expire_time": 0
  },
  "error": {
    "status": 0,
    "message": ""
  },
  "success": false
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `data` | object |  |
| `data.result` | integer (int32) | نتیجه اعتبارسنجی |
| `data.next_time` | integer (int64) | حداقل زمان انتظار برای امکان اعتبارسنجی مجدد در صورت اعتبارسنجی ناموفق |
| `data.expire_time` | integer (int64) | زمان انقضای توکن فعلی (پس از این زمان، توکن جدید باید درخواست شود و اعتبارسنجی مجددا انجام گیرد) |
| `error` | object | جزئیات خطای اجرای API |
| `error.status` | integer (int32) | کد خطا |
| `error.message` | string | پیغام خطا |
| `success` | boolean | نشان دهنده وضعیت اجرای API، مقدار true در صورت موفقیت و مقدار false در صورت مواجه شدن با خطا |
