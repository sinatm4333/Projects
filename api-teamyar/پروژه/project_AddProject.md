# ایجاد پروژه جدید

## آدرس

```
/api/project/AddProject
```

## درخواست

```json
{
  "title": "",
  "date_limit": 0,
  "date_start": 0,
  "category_id": 0,
  "description": "",
  "link_stage_sync": 0,
  "show_user_tasks": 0,
  "portal_perm_export": 0,
  "planning_date_limit": 0,
  "planning_date_start": 0,
  "portal_perm_add_task": 0,
  "show_amount_col_portal": 0,
  "show_first_step_to_all": 0,
  "show_progress_col_portal": 0,
  "show_amount_sum_col_portal": 0,
  "show_participation_col_portal": 0,
  "show_stage_description_portal": 0,
  "show_project_description_portal": 0
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `title` | string | ***فیلد عنوانپر کردن این فیلد اجباری می باشد |
| `date_limit` | integer (int64) | فیلد تاریخ پایان واقعیوارد کردن این فیلد اجباری نمی باشد.در صورتی که این داده اشتباه یا صفر یا وارد نگردد این مقدار به تاریخ روز +7 تبدیل می گردد |
| `date_start` | integer (int64) | فیلد تاریخ شروع واقعیوارد کردن این فیلد اجباری نمی باشد.در صورتی که این داده اشتباه یا صفر یا وارد نگردد این مقدار به تاریخ روز تبدیل می گردد |
| `category_id` | integer (int32) | ***فیلد شناسه ردهوارد کردن این فیلد اجباری می باشدبا پر کردن این فیلد رده پروژه ای که اد خواهد شد مشخص می گردد. |
| `description` | string | فیلد توضیحاتوارد کردن این فیلد اجباری نمی باشد .در صورتی که این فیلد مقداری نداشته باشد توضیحات پروژه نیز مقداری نخواهد داشت |
| `link_stage_sync` | integer (int32) | فیلد همگام سازی مراحل لینک شدهاین فیلد مقادیر 0 و 1 را قبول میکند و با وارد کردن عددی غیر 1 صفر در نظر گرفته میشود |
| `show_user_tasks` | integer (int32) | فیلد نمایش همه ی اقدام ها به کاربر در پورتالوارد کردن این فیلد اجباری نمی باشداین فیلد مقادیر 0 و 1 را قبول میکند و با وارد کردن عددی غیر 1 صفر در نظر گرفته میشود |
| `portal_perm_export` | integer (int32) | فیلد برون ریزیوارد کردن مقدار در این فیلد اجباری نمی باشداین فیلد مقادیر 0 و 1 را قبول میکند و با وارد کردن عددی غیر 1 صفر در نظر گرفته میشود |
| `planning_date_limit` | integer (int64) | فیلد تاریخ پایان برنامه ریزیوارد کردن این فیلد اجباری نمی باشد.در صورتی که این داده اشتباه یا صفر یا وارد نگردد این مقدار به تاریخ روز +7 تبدیل می گردد |
| `planning_date_start` | integer (int64) | فیلد تاریخ شروع برنامه ریزیوارد کردن این فیلد اجباری نمی باشد.در صورتی که این داده اشتباه یا صفر یا وارد نگردد این مقدار به تاریخ روز تبدیل می گردد |
| `portal_perm_add_task` | integer (int32) | دسترسی اضافه کردن تسک در پورتالپر کردن مقدار برای این فیلد اجباری نمی باشد.این فیلد مقادیر 0 و 1 را قبول میکند و با وارد کردن عددی غیر 1 صفر در نظر گرفته میشود |
| `show_amount_col_portal` | integer (int32) | نمایش ستون هزینه پروژه در پورتالپر کردن این فیلد اجباری نمی باشداین فیلد مقادیر 0 و 1 را قبول میکند و با وارد کردن عددی غیر 1 صفر در نظر گرفته میشود |
| `show_first_step_to_all` | integer (int32) | نمایش مرحله ی اول به همه کاربران در پورتالپرکردن این فیلد اجباری نمی باشداین فیلد مقادیر 0 و 1 را قبول میکند و با وارد کردن عددی غیر 1 صفر در نظر گرفته میشود |
| `show_progress_col_portal` | integer (int32) | نمایش ستون پیشرفت در پورتالپر کردن مقدار برای این فیلد اجباری نمی باشداین فیلد مقادیر 0 و 1 را قبول میکند و با وارد کردن عددی غیر 1 صفر در نظر گرفته میشود |
| `show_amount_sum_col_portal` | integer (int32) | نمایش ستون مجموع مشارکت ها در پورتالپرکردن این فیلد اجباری نمی باشداین فیلد مقادیر 0 و 1 را قبول میکند و با وارد کردن عددی غیر 1 صفر در نظر گرفته میشود |
| `show_participation_col_portal` | integer (int32) | نمایش ستون مشارکت من در پورتالپر کردن این فیلد اجباری نمی باشداین فیلد مقادیر 0 و 1 را قبول میکند و با وارد کردن عددی غیر 1 صفر در نظر گرفته میشود |
| `show_stage_description_portal` | integer (int32) | نمایش توضیحات استیج های پروژه در پورتالپرکردن این فیلد اجباری نمی باشداین فیلد مقادیر 0 و 1 را قبول میکند و با وارد کردن عددی غیر 1 صفر در نظر گرفته میشود |
| `show_project_description_portal` | integer (int32) | نمایش ستون توضیحات در پورتالپرکردن این فیلد اجباری نمی باشداین فیلد مقادیر 0 و 1 را قبول میکند و با وارد کردن عددی غیر 1 صفر در نظر گرفته میشود |

## پاسخ

```json
{
  "data": {
    "project_id": 0
  },
  "error": {
    "status": 0,
    "message": ""
  },
  "success": false
}
```

| فیلد | نوع | توضیح |
|------|-----|-------|
| `data` | object | دیتا |
| `data.project_id` | integer (int64) | شناسه پروژه که به واسطه این بات ساخته شده است |
| `error` | object | جزئیات خطای اجرای API |
| `error.status` | integer (int32) | کد خطای مربوطه |
| `error.message` | string | پیغام خطا مربوطه |
| `success` | boolean | نشان دهنده وضعیت اجرای API، مقدار true در صورت موفقیت و مقدار false در صورت مواجه شدن با خطا مربوطه |
